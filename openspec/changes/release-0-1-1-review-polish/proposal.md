## Why

После публикации 0.1.0 ревью неудобно в двух местах: колонка комментариев визуально сливается с документом, а переключатель показа/скрытия неочевиден. Сообщение в чате — сплошной служебный текст с идентификаторами, его трудно читать человеку, и нумерация не совпадает с номерами на подсветке. Интерфейс есть только на английском и русском, по умолчанию английский, хотя язык браузера известен.

## What Changes

- Широкая панель: граница между документом и колонкой комментариев; переключатель с явной подписью «Показать комментарии · N» / «Скрыть комментарии · N».
- Сообщение в чате в стиле Doc Review: видимый пузырь (заголовок с именем файла и числом, «Комментарий №N» с номером подсветки, текст, цитата блоком `>`) и скрытая от пользователя часть для агента (`visibility: agent-only`) с id, путём, цитатами и командой `resolve` — на английском.
- Сверка очереди при загрузке: история промптов хранит только видимую часть, поэтому «отправлен» определяется по совпадению пересобранного пузыря, а не по id.
- 10 языков интерфейса (en, zh-CN, es, pt-BR, ja, de, fr, ru, ko, hi), по умолчанию «Авто» по языку браузера; пузырь в чате — на языке интерфейса.
- Версия 0.1.1, README одной строкой о языках, новые скриншоты, обновление описания в маркетплейсе.

## Capabilities

### New Capabilities
- нет

### Modified Capabilities
- `openspec-document-review`: вид широкой панели и переключателя; формат сообщения агенту и сверка очереди.
- `openspec-plugin-distribution`: 10 языков и автоопределение вместо английского/русского с английским по умолчанию.

## Non-goals

- RTL-языки (ar, he, fa).
- Перевод агентской части сообщения и исходных документов.
- Миграция БД; изменение формата хранения комментариев.
- Новые функции ревью сверх перечисленного.
