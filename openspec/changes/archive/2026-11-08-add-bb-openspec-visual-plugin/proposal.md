## Why

В BB неудобно видеть состояние OpenSpec: какие требования действуют, какие изменения готовятся, какие документы готовы и что уже реализовано. Нужен визуальный навигатор со встроенным обсуждением документов, чтобы проверять работу агента без поиска файлов и ручного вызова CLI.

## What Changes

- Создать самостоятельный BB-плагин `bb-plugin-openspec` в отдельном вложенном Git-репозитории, подготовленном к публикации на GitHub.
- Добавить обзор выбранного проекта и окружения: действующие спецификации, активные изменения, архив, поиск и карточку изменения.
- Показывать готовность артефактов по схеме OpenSpec отдельно от выполнения задач; не выдавать наличие proposal за выполняющийся Propose.
- Сделать правую панель треда основным режимом: один рабочий столбец с переходом список → документ → назад. Адаптировать по ширине панели, не окна BB. Отдельная страница — дополнительный обзор.
- Добавить в панель треда связи многие-ко-многим: один чат работает с несколькими спеками/изменениями, одна спека — с несколькими чатами. Показывать связи в обе стороны; открытый документ — независимый выбор для просмотра.
- Адаптировать Markdown-ветку MIT-плагина Doc Review: выделения, комментарии, ответы, черновики, передача замечаний агенту и статусы обработки. Установка исходного Doc Review не требуется.
- Сохранить штатный flow OpenSpec: плагин показывает архив, но не связывает обсуждения с архивными документами и не управляет архивацией чатов. Обсуждения сохраняются у исходного документа без автоматического или ручного переноса.
- Поддержать английский и русский интерфейсы; публичные описание и README писать на английском. Язык исходных документов не менять при смене UI.
- Оставить первую версию визуальной: без запуска Propose/Apply, архивации, редактирования чекбоксов и произвольного редактирования спек из интерфейса. Передача замечаний агенту — только явное действие пользователя.

## Capabilities

### New Capabilities

- `openspec-visual-workspace`: выбор контекста, навигация по спецификациям/изменениям/архиву, правдивый прогресс, связи многие-ко-многим с тредами и обновление данных.
- `openspec-document-review`: встроенное обсуждение Markdown, передача замечаний агенту и сохранение истории независимо от архивации OpenSpec и чатов.
- `openspec-plugin-distribution`: самостоятельный пакет BB, EN/RU, английская публичная документация, лицензирование и установка из GitHub.

### Modified Capabilities

Нет: в новом репозитории ещё нет действующих спецификаций.

## Impact

- Новый плагин с frontend, backend и host entry через публичный BB SDK; без изменения ядра BB и исходного Doc Review.
- OpenSpec CLI и Markdown остаются источником истины; собственное хранилище содержит только обсуждения, настройки и привязки.
- CLI и файлы читаются на хосте выбранного окружения. Недоступность хоста и неподдерживаемая версия показываются как ошибки, не как пустой проект.
- Основа адаптации: https://github.com/xMinor-1/bb-plugins/tree/main/plugins/doc-review (MIT). Сохранить copyright и лицензию для заимствованного кода; зафиксировать upstream SHA при переносе.
- Первая версия поддерживает repo-local OpenSpec, включая ближайший корень в выбранном checkout. Stores, глобальный defaultStore, общая идентичность между worktree и импорт истории исходного Doc Review не входят в первый релиз.
- Публикация GitHub выполняется после реализации и проверок; владелец репозитория, публичность и лицензия собственного кода уточняются перед публикацией.
