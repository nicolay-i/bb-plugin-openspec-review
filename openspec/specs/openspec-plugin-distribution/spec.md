# openspec-plugin-distribution Specification

## Purpose
Обеспечивает самостоятельную установку и публикацию OpenSpec-плагина для BB, поддержку русского и английского интерфейсов и соблюдение лицензий заимствованного кода.

## Requirements

### Requirement: Самостоятельный пакет

Плагин SHALL иметь отдельный Git-репозиторий, собственную идентичность BB, сборку, документацию и навыки агента. Он SHALL работать рядом с Doc Review без конфликтов команд, состояния и глобального перехвата Markdown. Установка SHALL использовать публичный механизм BB без патчей ядра.

#### Scenario: Совместная установка
- **WHEN** OpenSpec-плагин и Doc Review установлены одновременно
- **THEN** обсуждения и команды каждого остаются независимыми, а OpenSpec открывает свои документы во встроенном ревью без замены общего Markdown-просмотрщика

### Requirement: Публикация и происхождение кода

Публичные описание и README SHALL быть на английском и объяснять назначение, установку, требования, ограничения, EN/RU и происхождение адаптированного кода. Дистрибутив SHALL сохранять MIT-уведомление Doc Review и сведения о заимствованной версии. Репозиторий SHALL NOT включать секреты, рабочую базу обсуждений, node_modules или исследовательские копии репозиториев.

#### Scenario: Проверка релиза
- **WHEN** собирается версия для публикации
- **THEN** в ней присутствуют необходимые лицензионные уведомления и установка из GitHub воспроизводится по английскому README на поддерживаемой версии BB

### Requirement: Явные требования совместимости

Плагин SHALL документировать и проверять поддерживаемый контракт OpenSpec CLI и диапазоны BB/SDK. Неподдерживаемая установка SHALL завершать затронутую операцию явной диагностикой, без запасного парсера, автоматической установки CLI или скрытого обновления зависимостей.

#### Scenario: Неподдерживаемый CLI
- **WHEN** CLI не предоставляет необходимый JSON-контракт
- **THEN** операция прекращается с указанием установленной и требуемой версии, без попытки разобрать текстовый вывод

### Requirement: Языки интерфейса

Плагин SHALL предоставлять полный интерфейс на 10 языках: en, zh-CN, es, pt-BR, ja, de, fr, ru, ko, hi. Выбор языка SHALL быть явным в настройках плагина; значение по умолчанию — «Авто»: первый поддерживаемый язык из языков браузера (точное совпадение, затем основной подтег), иначе английский. Переключение SHALL менять собственные подписи, статусы, пустые состояния, сообщения ошибок и видимую часть сообщения в чате без перевода исходных документов, имён файлов или структурных маркеров OpenSpec. Оригинальные диагностические сообщения внешних инструментов SHALL быть отличимы от локализованных пояснений плагина. Ранее сохранённые значения `en` и `ru` SHALL оставаться валидными.

#### Scenario: Переключение на русский
- **WHEN** пользователь выбирает русский язык
- **THEN** собственный интерфейс отображается по-русски, выбор сохраняется, а документы остаются побайтно неизменными

#### Scenario: Автоопределение
- **WHEN** язык в настройках — «Авто», а браузер сообщает `de-AT, en`
- **THEN** интерфейс и видимая часть сообщения в чате отображаются по-немецки

#### Scenario: Неподдерживаемый язык браузера
- **WHEN** язык в настройках — «Авто», а браузер сообщает только `ar`
- **THEN** интерфейс отображается по-английски

#### Scenario: Полнота переводов
- **WHEN** выполняются автотесты
- **THEN** каждый из 10 словарей содержит те же ключи, что и английский, без пустых значений
