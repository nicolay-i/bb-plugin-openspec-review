## Context

Плагин открыт в правой панели треда; `threadId` даёт проект и окружение. Отдельная страница требовала выбора окружения среди checkout на разных хостах — источник сложности.

## Decisions

- **Контекст = тред.** Панель берёт `projectId`/`environmentId` из `threads.get`. RPC `contexts`, `navPanel` и блок технического контекста удаляются.
- **Автопоиск тредов.** `bb.sdk.threads.search({ query: changeId })`, активная группа; оставляем треды того же проекта, где текст совпадения содержит id изменения дословно. Поиск нечёткий, поэтому дословная проверка обязательна. Для спек поиска нет: короткие id дают ложные совпадения.
  - shortcut: сниппет совпадения может обрезать id — такой тред не найдётся.
- **Статусы `open | sent | closed`.** Отправка — только `open`, всегда в текущий тред, режим `queue-if-active`. Закрыть может пользователь и агент (`resolve`). Удаление — физическое.
- **Без истории.** Исчезнувший документ сохраняет записи в хранилище (поколения остаются), но в UI не показывается; новый документ по тому же пути начинает с нуля.
- **Раскладка.** Контейнерный запрос по ширине панели: ≥ 720 px — документ и колонка рядом; уже — колонка заменяет документ. Клик по комментарию в узком режиме возвращает документ с подсветкой.

## Risks

- Миграция удаляет ответы агента и ручные связи — данные плагина локальные, плагин не опубликован.
- Поиск BB может вернуть не все упоминания (лимиты, сниппеты).
